# Minishell

## Description

The goal of this project is to build a functional shell in C. It need to be able to let the user uses basic command, pipes and redirection as well as environment variable expansions and the cd, echo, env, exit, export, pwd, unset built-in commands.

## Instructions

To be able to use the program you need to run make.
```
'make' - compile minishell files
'make all' - compile all minishell files
'make clean' - delete all *.o files
'make fclean' - delete all *.o and *.a (executable) files
'make re' - Does make fclean then make all, recompile minishell
```
Then use `./minishell` without any arguement.
You can now use it like a shell.
To quit minishell you can type 'exit' or use 'ctrl + D'.
